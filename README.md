# PractiMentor — Plataforma

Documentación transversal del proyecto: decisiones de arquitectura (ADRs), guía de incorporación del equipo y, más adelante, la infraestructura (Docker Compose, Kubernetes, Terraform).

Parte del proyecto **PractiMentor**, plataforma web de empleabilidad con inteligencia artificial para estudiantes universitarios (curso Herramientas de Desarrollo, UTP). Documentación y decisiones: [`practimentor-platform`](https://github.com/practimentor/practimentor-platform).

## Qué no le corresponde

No contiene código de aplicación: cada servicio vive en su propio repositorio.

## Cómo ejecutarlo

No hay nada que ejecutar. Empieza por `docs/onboarding.md` y `docs/decisions/index.md`.
